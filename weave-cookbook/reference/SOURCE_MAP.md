## Live verification

On 2026-08-02, the examples 00 and 01 instrumentation path ran live in both languages against wandb.ai, and the resulting spans were confirmed through the Weave service API (`/agents/spans/query`). The later name-only response contract and optional two-turn control flow are covered by offline tests, but the two-turn UI shape has not been re-captured live:

- Each run produced one conversation for `game-night-agent` with a `conversation_id` shared by its spans.
- Each recommendation turn logged an `invoke_agent` root span with an `execute_tool` child (`tool_name: search_catalog`) and a `chat` child carrying the model ID plus provider-reported token usage.
- The early-return run (`--minutes 10`) logged a turn whose only child is the tool span.
- With `implicitly_patch_integrations: False`, `calls/stream_query` returned zero op calls for the same window — the model call is logged exactly once, as a span.
- The Inference call succeeded without `WANDB_ENTITY` set and without the optional `project` header.

Tested dependency versions are pinned in `python/uv.lock` and `typescript/package-lock.json`, and summarized in [COMPATIBILITY.md](COMPATIBILITY.md).
